New in this version

Smaller installers for both 32-bit and 64-bit ARM phones, with clear choices if Android reports an incompatible installer. Each contains the full app with the same features and audio quality.

Native background audio, Android media controls, queue advancement without the app screen, playback recovery after Activity recreation, cached searches, a maintained extraction engine, and clearer download errors. Downloads save completed songs in Library and Offline. Optional recovery copies go to Downloads/Sonora. The current download continues when you switch apps; return to finish saving and continue playlist downloads.

YouTube remains connection-dependent

YouTube streaming uses an unofficial on-device resolver. In current live tests, both streaming and downloading Julia Boutros “Moqawem” and a short public clip were refused by YouTube's bot checks. This release does not claim those failures are fixed. Search and the native background player work independently of that upstream refusal. A separate real HTTPS catalog stream passed screen-off playback without a saved song.
